# الملف التعريفي لربائد · الإصدار 4

صفحة تفاعلية واحدة بالعربي والإنجليزي، تشتغل على الجوال والكمبيوتر، ومنها تطلع 4 ملفات PDF.

## المجلدات

| المجلد | وش فيه |
|---|---|
| `PDF/` | الأربع ملفات الجاهزة للإرسال: عربي وإنجليزي، كل واحد بنسخة كمبيوتر (16:9) ونسخة جوال (طولية) |
| `dist/` | الموقع الجاهز للرفع: `profile/` (عربي) و`en/profile/` (إنجليزي) |
| `content/` | **كل النصوص هنا.** `ar.json` و`en.json` للنصوص، و`site.json` للأرقام والروابط والشعارات وإعدادات الحاسبة |
| `src/` | التصميم (`styles.css`) والتفاعل (`app.js`) |
| `media/` | الصور والشعارات والفيديوهات الأصلية |
| `tools/` | توليد PDF، وفحص الأداء، ولقطات المراجعة |

## تعديل النصوص

1. عدّل `content/ar.json` أو `content/en.json` (أو `site.json` لرقم أو رابط).
2. شغّل:

```bash
python build.py
```

الأمر يبني الصفحتين ويولّد الأربع ملفات PDF وصورتي المعاينة. يحتاج Python مع Pillow، وNode، وGoogle Chrome على الجهاز.
أول مرة فقط: `npm install`.

## الرفع على الموقع (للمطوّر)

الموقع Next.js. انسخ محتوى `dist/` إلى مجلد `public/`:

- `public/profile/…` ← الصفحة العربية وكل الملفات (`assets/`)
- `public/en/profile/index.html` ← الصفحة الإنجليزية (تستخدم نفس `profile/assets/`)

وأضف rewrites عشان الروابط القصيرة تشتغل:

```js
// next.config.js
async rewrites() {
  return { beforeFiles: [
    { source: '/profile', destination: '/profile/index.html' },
    { source: '/en/profile', destination: '/en/profile/index.html' },
  ] };
}
```

الروابط داخل الصفحة نسبية، فالمجلد يشتغل كمان لو انفتح مباشرة من الكمبيوتر بدون سيرفر.
صورة المعاينة في الواتساب (`og-ar.png` / `og-en.png`) تشتغل بعد الرفع فقط، لأنها تحتاج رابط كامل.

## قرارات مهمة

- **صورة الاعتماد الورقي:** الأسماء والشعارات والتواقيع والأختام مغطّاة بتغبيش داخل الصورة نفسها (`tools/redact.py`)، فما ينكشف شي لو أحد نزّل الصورة.
- **فيديوهات المقارنات الخمسة:** كلها موجودة بطلب أحمد (31/10/2026). في فيديو 1 الورقة الحقيقية مغطاة أسماؤها وأختامها بنفس صورة `approval-paper-redacted.jpg`، إطاراً بإطار (`tools/redact_clip.py`)، بس ورقة ربائد في نفس الفيديو لسا فيها الأسماء. فيديو 2 و3 فيهم أسماء حقيقية (مشروع الأصالة، مرسلين بالإيميل، مجلدات OneDrive). الفيديو يشتغل لحاله (بدون صوت) لما توصله، ويوقف لما تطلع منه. على «توفير البيانات» أو النت البطيء، ينتظر زر التشغيل.
- **حاسبة التأخير:** المعادلة المعتمدة في `dev-ticket-delay-calculator.md`: تكلفة المال 8% سنوياً على المصروف حتى الآن (قيمة المشروع × نسبة الإنجاز) عن أيام التأخير. الافتراضي 60 مليون، 7 أيام، 50% = 46,027 ر.س. اختبار `node tools/smoke.mjs` يتحقق من جدول القبول في التذكرة.
- **الأيقونات:** من الملف التعريفي V3 (`media/icons`)، وتتلوّن من CSS.
- **الأرقام:** «+1,900 معاملة اعتماد» بدون مدة. الضمان 60 يوماً.
- **الباقات (قسم 13):** الأساسية والنمو والاحترافية بمزاياها، بدون أسعار، زي الملف القديم. نصوصها بـ `plans` في ملفي المحتوى.
- **التواصل:** زر الواتساب العائم وأزرار الواتساب على رقم الشركة، وصفحة التواصل فيها رقم أحمد وإيميله ورقم الشركة.

## الأداء

مقاس على جوال (390px) مع إبطاء المعالج 4 مرات (`node tools/perf.mjs`):

| الصفحة | 4G | 3G ضعيف (400 كيلوبت) |
|---|---|---|
| العربية | يظهر المحتوى خلال 2.3 ث | 3.4 ث |
| الإنجليزية | 1.4 ث | 2.7 ث |

أول شاشة تحمّل تقريباً 300 إلى 450 كيلوبايت. باقي الصور تتحمّل مع النزول في الصفحة، والفيديو ما يتحمّل إلا لما الزائر يضغط تشغيل.
