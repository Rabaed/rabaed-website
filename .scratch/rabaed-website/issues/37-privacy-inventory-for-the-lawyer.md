# 37: Privacy inventory for the lawyer

**What to build:** A plain-language document the founders can hand to their lawyer, listing exactly what the site now collects, where it is stored, who can reach it and for how long — so the Arabic Privacy Policy can be updated before launch.

**Blocked by:** 27, 28

**Status:** ready-for-agent

- [ ] Every field collected by every form is listed, in plain language, not technical terms
- [ ] Document uploads called out specifically: IBAN certificates and commercial registrations, where they are stored and who can retrieve them
- [ ] Storage location, retention period and access controls stated for each category
- [ ] Analytics data collection described, including that it is cookie-free
- [ ] Email processing described: the Microsoft 365 mailbox that sends alerts and confirmations
- [ ] Written in Arabic and English, ready for the lawyer to work from
- [ ] Delivered to the founders as a document, not only as a file in the repository

**Note:** the Privacy Policy currently describes a site that collects nothing. Launching without this is a real exposure under Saudi personal data law, given what the Referral form collects.
